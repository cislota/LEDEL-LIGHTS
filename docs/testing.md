# Проверка изменений

Выполняйте только проверки, связанные с изменённой частью проекта.

## Frontend

```bash
cd frontend
npm run build
```

`npm run lint` сейчас завершается ошибкой, потому что скрипт вызывает удалённую в Next.js 16 команду `next lint`. До исправления конфигурации эту проверку нельзя считать доступной.

## Backend и инфраструктура

```bash
docker compose config
docker compose up -d --build
docker compose ps
docker compose logs backend
```

После запуска проверьте:

```bash
curl http://localhost:8000/api/health
```

Ожидается ответ со статусом API и состоянием подключения к PostgreSQL.

## Изменение базы данных

Если менялись модели:

1. Создайте миграцию Alembic.
2. Примените всю цепочку миграций к чистой тестовой базе.
3. Проверьте обновление существующей базы.
4. Сверьте модели SQLAlchemy и Pydantic-схемы.

## Синхронизация каталога

Используйте только обезличенную локальную фикстуру. Проверьте:

- первый запуск создаёт товар;
- повторный запуск не создаёт дубликат;
- изменённые данные товара обновляются;
- ошибка одного товара не повреждает уже сохранённые данные;
- статистика записывается в `sync_logs`.

## Ограничения проверки

В репозитории нет полноценного автоматического набора тестов. Файл `backend/test_jwt_key.py` проверяет только отказ запуска без `JWT_SECRET_KEY` и не заменяет тесты API, моделей и синхронизации.

Не отмечайте проверку успешной, если команда не запускалась или завершилась ошибкой.
